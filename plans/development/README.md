# plans/development

Implementation plans and the living index (`00-implementation-plan.md`).

Each new plan is one dated Markdown file named `YYYY-MM-DD-<slug>.md` in this
directory. Architecture decisions are ADRs in [`plans/architecture/`](../architecture/README.md),
written with the `repo-memory` skill. Work is tracked in Plane. See ADR-0007 for why
plans are not kept as OpenSpec changes.
