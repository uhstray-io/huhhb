# plans/development

Implementation plans. `00-implementation-plan.md` is the retired index, kept as history only.

Each new plan is one dated Markdown file named `YYYY-MM-DD-<slug>.md` in this
directory. Architecture decisions are ADRs in [`plans/architecture/`](../architecture/README.md),
written with the `repo-memory` skill. Work is tracked in Plane. See ADR-0007 for the decision.
