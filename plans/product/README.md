# plans/product

Product-inception artifacts, one directory per initiative:
`<initiative-slug>/{brief.md,prd.md,architecture.md}` (the `product-inception`
skill — opt-in, rare). The PRD's Epic Queue is filed as Plane work items on
hand-off; architecture `## Decisions` are recorded as architecture decisions
(`repo-memory`) on approval. Empty is normal — most repos never run inception.
